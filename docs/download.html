02CHANGELOG

更新日志

v1.0.6-beta

最近更新：2026.10.30。查看 GitHub Releases 获取完整的版本发布记录。

GitHub Releases

v1.0.6-beta

2026.10.30
  • 适配了新的数据结构，优化了排版逻辑。

v1.0.5-beta

2026.09.14
  • 更换为 release 构建（仍使用 debug 证书签名，可直接覆盖安装），消除 debug 包不走编译优化导致的高耗时。
  • 修复主页左右滑动切换周次时卡顿、滑动起步明显掉帧的问题；滑动时主线程单帧耗时中位数由约 9ms 降至 1.3ms，换周首帧由约 240ms 降至 30ms 以内。
  • APK 体积由约 25MB 降至 12.8MB。
  • 课程卡片排版调整：课程名最多四行；教室、教师各占一行，教室优先显示教室号。
  • 移除卡片上的单双周文字标识，非本周课程仍以降低透明度区分。

早期版本更新

v1.0.1 – v1.0.4-beta
  • 适配常见教务系统，一键导入课表。

关于 GSH课程表

GSH课程表（Great Schedule Helper）是一款专为学生打造的课表管理应用。基于 WakeUpSchedule 开源项目二次开发，适配新版正方教务系统。

致谢

  • 北邮适配 — XIANFEI
  • GSH 开发 — 2LNZ，UI 优化与设计，银杏学院适配与 Material 3 迁移
  • 银杏学院适配 — 2LNZ
  • 早期贡献 — XIANFEI
